# VRC-Unity-Essentials


A few useful unity tools for making vrc avatars.


VCC Repository Link:

https://raw.githubusercontent.com/APOL-StarLight/VRC-Unity-Essentials/main/vcc.json

## Advanced Hierarchy Search

Search for game objects by Name, Tag, Components,Activity Status or missing scripts. 

## Animation Path Editor

Allows you to rename, Copy, or Delete animation property paths in an Animation Controller or in a single Animation Clip.

## Bone Counter

Counts The number of bones in your avatar, this excludes 'EditorOnly' bones and their children.

## Check Animation Controller

Checks the selected Animation Controller for the following:

-States with empty motion fields.

-Animations with no Keyframes.

-Missing identifiers.

-Mixed WD (Write Defaults On/Off).

## Full Hierarchy Transform Copier

This tool copies the transforms (position, rotation, and scale) from the 'Copy Transforms From' object to the 'Paste Transforms Into' object, including all their children. The operation is undoable.

## Hierarchy Path Viewer

This tool displays the hierarchy path of the selected object in the Unity Editor. You can adjust the number of parent objects to exclude from the path. The hierarchy path updates automatically when a new object is selected.
